Git dan GitHub

Git mencatat riwayat perubahan kode, dan GitHub menyimpannya secara online. Setiap perubahan disimpan sebagai commit, dan saya membuat 8 commit. Branch dipakai untuk mengerjakan fitur terpisah dari branch utama (saya membuat branch feature/readme), lalu digabung lewat merge. Saat dua perubahan menyentuh baris yang sama, terjadi merge conflict yang harus diselesaikan manual; saya mengalaminya di file README ketika deskripsi diubah di dua tempat berbeda, lalu saya selesaikan lewat commit merge: resolve README conflict. Pull Request dipakai untuk mengajukan penggabungan branch: saya membuat Pull Request #1 dari branch feature/readme untuk menambahkan README. File .gitignore menjaga file yang tidak perlu (seperti .env dan node_modules) tidak terunggah.

npm

npm mengelola package yang dipakai proyek. Daftar package dan perintah proyek ada di package.json. dependencies adalah package yang dibutuhkan aplikasi saat berjalan, sedangkan devDependencies hanya dibutuhkan saat pengembangan. Proyek ini hanya memakai devDependencies, yaitu typescript dan vite, karena hasil build berupa file statis. Versi memakai semantic versioning MAJOR.MINOR.PATCH: typescript memakai ~7.0.2 (hanya pembaruan patch), sedangkan vite memakai ^8.3.6 (pembaruan minor dan patch). npm scripts yang saya pakai: dev (menjalankan vite untuk server lokal), build (menjalankan tsc && vite build), dan preview (menjalankan vite preview untuk melihat hasil build).

TypeScript

TypeScript menambahkan tipe pada JavaScript sehingga kesalahan tipe ketahuan sebelum aplikasi dijalankan. Contoh penggunaannya di aplikasi ini:

  • Primitive types: string, number, dan boolean, misalnya let animasiAwal: boolean = true dan properti id: number serta judul: string pada interface Tugas.
  • Array: const kataJudul: string[] dan let daftarTugas: Tugas[].
  • Interface: interface Tugas dengan properti id, judul, matkul, deadline, dan status.
  • Type alias dan union type: type Status = 'Belum Selesai' | 'Selesai' dan type FilterType = 'Semua' | Status.
  • Generics sederhana: fungsi loadData<T>(key: string, fallback: T): T dan saveData<T>(key: string, data: T): void di src/storage.ts, yang saya panggil sebagai loadData<Tugas[]> dan saveData<Tugas[]> untuk menyimpan dan membaca daftar tugas.

Vite

Vite adalah alat pengembangan yang menjalankan server lokal lewat perintah npm run dev dan membangun aplikasi untuk produksi lewat npm run build. Hasil build berupa file statis yang kemudian saya deploy di Vercel.

Compiler, transpiler, dan bundler

  • Compiler menerjemahkan kode sumber ke bentuk lain. Di proyek ini, perintah tsc pada script build memeriksa tipe TypeScript sebelum build dilanjutkan.
  • Transpiler menerjemahkan antar bahasa yang selevel, yaitu TypeScript menjadi JavaScript yang bisa dijalankan browser. Itu terjadi saat Vite memproses kode.
  • Bundler menggabungkan banyak file dan package menjadi file yang lebih sedikit dan dioptimalkan untuk browser. Di proyek ini hal itu terjadi saat vite build dijalankan.

Environment variables

File .env menyimpan konfigurasi yang berbeda antar lingkungan, dan .env.example memberi contoh isinya tanpa nilai rahasia. Di Vite, hanya variabel berawalan VITE_ yang bisa dibaca kode di browser, jadi password atau API key rahasia tidak boleh ditaruh di situ. File .env masuk .gitignore sehingga tidak ikut ke GitHub. Variabel yang saya pakai: VITE_APP_NAME (nama aplikasi) dan VITE_APP_VERSION (versi aplikasi), keduanya non-rahasia.
